# Nomotica

Static GitHub Pages site for Nomotica.

## Structure

- `index.html` — release list homepage
- `consult.html` — commissioned research page
- `products.html` — quarterly/product page
- `styles.css` — minimal visual system
- `.nojekyll` — disables Jekyll processing

## GitHub Pages

Enable GitHub Pages from the repository settings using the `main` branch and root folder.
